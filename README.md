# Crime Analysis Dashboard

An interactive crime analysis dashboard developed using Excel and Power BI to analyze crime patterns, victim demographics, weapon usage, and crime-prone areas.

## Project Overview

This project focuses on analyzing crime data to identify patterns and trends across different years, crime types, locations, victim demographics, and weapons used.

## Tools & Technologies

- Microsoft Excel
- Power BI
- DAX
- Power Query

## Key Features

- Crime trend analysis across different years
- Analysis of victim demographics
- Weapon usage and crime analysis
- Identification of crime-prone areas
- Interactive year-based filtering
- KPI cards and data visualizations
- Crime and weapon trend forecasting

## Project Files

| File | Description |
|---|---|
| `Crime_Analysis_Dashboard.pbix` | Main Power BI dashboard |
| `Measure.pbix` | Power BI measures |
| `Crime dataset.csv` | Dataset used for analysis |

## Dashboard Sections

- Crime Analysis
- Victim Analysis
- Weapon Analysis
- Crime Trends
- Forecasting

## Objective

To transform raw crime data into meaningful visual insights that can help understand crime patterns, trends, and contributing factors.
